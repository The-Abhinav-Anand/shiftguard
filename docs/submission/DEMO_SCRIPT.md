# Demo video script (target 2:40, hard limit under 3:00)

Record real UI outcomes only. Do not stage or edit a model response to look live. If the
day's model allowance is used up during recording, show the cap message and say so.
Never show the API key, `.env`, terminal history or browser devtools with headers.

| Time | Screen | Narration (about 25 words per 10 s) |
|---|---|---|
| 0:00–0:20 | About SHIFTGUARD (`/about`), "When inputs shift" | A deployed model still returns probabilities when a data feed drops fields. Are they still right? SHIFTGUARD measures how calibration holds up when inputs go missing. |
| 0:20–0:55 | Bank calibration workbench (`/`) → "Choose an approved analysis" → Run analysis; job ledger moves to completed; open the saved result | We run an approved Bank analysis. It runs as a durable job on a separate worker, and every artifact is hash-verified before the app shows it. |
| 0:55–1:35 | Reliability plot, budget curve, decision-loss, pattern-versus-rate; fallback details | At 50 target labels, three target maps lower Brier score, but log loss gets worse in every shifted cell. The metric matters, and the app shows the adverse results too. |
| 1:35–2:10 | Results assistant: ask "Compare target temperature with the source-only baseline at budget 50 for the saved result." Show the tool trace and provenance | Nemotron on Nebius Token Factory picks approved tools; every number you see is rendered from the stored record, not generated by the model. |
| 2:10–2:30 | General chat (unverified label); agent status with remaining daily allowance | General chat is separate and labelled unverified. Both assistants share a hard daily budget with no retries, so spending can't run away. |
| 2:30–2:40 | About page footer / repository | Built with NVIDIA Nemotron on Nebius Token Factory. The source is public, and the live app is open for judging. |

Before recording, check:
- The saved result in the shot is the release-build experiment ID listed in RELEASE_CHECKLIST.
- `/api/v1/agent/status` shows enough remaining allowance for at least three provider calls.
- The video is uploaded as public or unlisted-public on YouTube and is under 3:00.
